# Pro in mont jedan j.d.o.o. – web projekt

Statička, responsive web stranica pripremljena za GitHub + Netlify.

## Kontakt obrazac
Obrazac koristi Netlify Forms (`data-netlify="true"`). Nakon deploya:
1. Otvoriti Netlify projekt.
2. Otvoriti Forms / Forms notifications.
3. Dodati email notification za obrazac `kontakt`.
4. Kao primatelja postaviti `proinmont1@gmail.com`.

Netlify će tada zaprimati obrasce i slati obavijesti na navedenu adresu.

## Prije javne objave
- Dodati službenu e-mail adresu tvrtke kada bude dostupna.
- Provjeriti pravne podatke društva (MBS, registrirane djelatnosti i nadležni sud) prema službenim podacima.
- Provjeriti licence za sve fotografije koje nisu vlastite.
- Zamijeniti privremene fotografije stvarnim projektima gdje je moguće.
- Ako se uvede Google Analytics, Meta Pixel, Google Ads ili drugi alat, ažurirati cookie consent i politiku kolačića.
